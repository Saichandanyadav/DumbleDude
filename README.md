# DumbleDude Fitness | Be Legendary

DumbleDude is a high-performance, dark-themed fitness platform designed for elite training environments. Built with a focus on aggressive aesthetics, modern motion design, and mobile-first responsiveness, it serves as the digital headquarters for legends in the making.

---

## 🚀 Tech Stack

* **Framework:** Next.js 14 (App Router)
* **Styling:** Tailwind CSS
* **Animations:** Framer Motion
* **Icons:** Lucide React
* **Font:** Custom Display Sans (Italicized for speed/energy)
* **Components:** Client-side Optimized

---

## ✨ Features

### 1. **Ultra-Responsive Navigation**

* Dynamic background blur on scroll.
* Oversized brand logo integration for high visibility.
* Mobile-optimized slide-down menu.

### 2. **"Real Results" Infinite Slider**

* Auto-scrolling transformation cards.
* **Body Recomposition Focus:** Interactive hover states and progress bar animations.
* **High-Impact Visuals:** Extra-wide card layouts ($1000px$+) for cinematic desktop viewing.

### 3. **Brutalism-Inspired Footer**

* Clean grid layout for training zones and HQ details.
* Integrated newsletter "Join the Grind" subscription section.
* Social connectivity icons with brand-specific hover effects.

### 4. **SEO & Branding**

* Custom Metadata configuration.
* Dynamic Favicon/Tab Header integration using the "Double-D" bicep logo.
* Optimized for high-performance lighthouse scores.

## 🛠️ Getting Started

1. **Clone the repo:**
```bash
git clone https://github.com/your-username/dumbledude-fitness.git

```


2. **Install dependencies:**
```bash
npm install

```


3. **Run the development server:**
```bash
npm run dev

```


4. **Build for production:**

```bash
    npm run build
    ```

---

## 💡 Customization Note
